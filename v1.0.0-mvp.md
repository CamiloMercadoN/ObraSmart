# ObraSmart v1.0.0-mvp

**Fecha de liberación:** 07-08-2026  
**Estado:** Liberada  
**Tipo de versión:** Producto mínimo viable  
**Ambiente:** Producción  

## Descripción

La versión v1.0.0-mvp corresponde a la línea base utilizada para la evaluación y
liberación productiva de ObraSmart. La versión integra las funcionalidades
desarrolladas y validadas para el alcance definido del producto mínimo viable.

## Funcionalidades incluidas

- Registro y autenticación de usuarios.
- Dashboard principal (Solo maqueta).
- Gestión de clientes.
- Gestión de insumos y precios de referencia.
- Gestión de etiquetas y unidades controladas.
- Creación y actualización de estructuras APU.
- Cálculo automático de costos mediante APU.
- Consulta y reutilización de estructuras APU.
- Creación y gestión de presupuestos.
- Duplicación de presupuestos y estructuras APU.
- Conservación de antecedentes históricos asociados al presupuesto.
- Configuración de información comercial.

## Despliegue

La versión fue empaquetada mediante Docker y publicada en Microsoft Azure.

- Imagen: `obrasmartserver:v1.0.0-mvp`
- Registro: `obrasmartacr.azurecr.io`
- Ejecución: Azure Container Apps
- Base de datos: Azure SQL
- Región: West US 3

El frontend Vue 3 y la API ASP.NET Core se distribuyen mediante una única imagen
Docker. Los archivos estáticos generados por Vue son servidos mediante Kestrel
junto con la API REST.

## Observaciones

La estrategia de despliegue mediante una única unidad contenedorizada fue adoptada
para simplificar la liberación y operación del MVP, manteniendo el desacoplamiento
lógico entre frontend y backend.
